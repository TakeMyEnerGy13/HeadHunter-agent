# HeadHunter Agent

Telegram-бот для поиска вакансий на HH, оценки релевантности резюме и генерации сопроводительных писем через LLM.

## Что умеет

- Ищет вакансии на HeadHunter по ключевым словам.
- Фильтрует вакансии по словам-исключениям.
- Запоминает просмотренные вакансии, чтобы не присылать одно и то же повторно.
- Оценивает вакансию относительно резюме.
- Генерирует сопроводительное письмо.
- Учитывает примеры вашего стиля и предпочтения к письму.
- Может написать письмо вручную по тексту вакансии или ссылке.
- Запускает автопоиск по расписанию.

## Стек

- Python
- aiogram
- aiosqlite
- httpx
- OpenAI-compatible LLM API
- APScheduler

## Быстрый старт

1. Склонируйте репозиторий:

```powershell
git clone https://github.com/TakeMyEnerGy13/HeadHunter-agent.git
cd HeadHunter-agent
```

2. Создайте и активируйте виртуальное окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

3. Установите зависимости:

```powershell
pip install -r requirements.txt
```

4. Создайте `.env` из примера:

```powershell
Copy-Item .env.example .env
```

5. Заполните `.env`:

```env
LLM_API_KEY=your_llm_api_key_here
LLM_BASE_URL=http://localhost:20128/v1
MODEL_NAME=kr/claude-sonnet-4.5
HH_USER_AGENT=hh-agent/0.2 (+https://github.com/TakeMyEnerGy13/HeadHunter-agent)
TG_BOT_TOKEN=your_telegram_bot_token_here
TG_CHAT_ID=your_telegram_chat_id_here
```

6. Запустите бота:

```powershell
python .\main_bot.py
```

## Как пользоваться

После `/start` бот покажет меню в Telegram.

Основной сценарий:

1. Загрузите резюме через кнопку `Изменить резюме`.
2. Добавьте ключевые слова через `Изменить ключи`.
3. При необходимости добавьте стоп-слова через `Изменить исключения`.
4. Добавьте примеры стиля через `Стиль письма`.
5. Добавьте пожелания к письмам через `Предпочтения`.
6. Нажмите `Искать сейчас` или включите автопоиск.

Для ручной генерации письма нажмите `Написать письмо` и отправьте текст вакансии или ссылку.

## Переменные окружения

- `TG_BOT_TOKEN` - токен Telegram-бота.
- `TG_CHAT_ID` - ID чата для уведомлений по умолчанию.
- `LLM_API_KEY` - ключ для OpenAI-compatible API.
- `LLM_BASE_URL` - URL LLM API.
- `MODEL_NAME` - модель для анализа и генерации писем.
- `HH_USER_AGENT` - User-Agent для запросов к HH API.

## Локальные данные

Бот хранит настройки пользователей и историю вакансий в локальной SQLite-базе `bot_data.sqlite`.

Этот файл не должен попадать в git: в нем могут быть персональные данные, резюме и история поиска.

## Известная проблема с HH API

Иногда `api.hh.ru` может возвращать `403 Forbidden` даже на публичный `GET /vacancies`.
В текущей версии бот выводит диагностическое сообщение с `request_id` и `errors`, чтобы его можно было отправить в поддержку HH.

Если ошибка воспроизводится:

1. Скопируйте `request_id` из сообщения бота.
2. Напишите в поддержку HH API: `api@hh.ru`.
3. Приложите URL запроса, время запроса и текст ошибки.
